# Support

Use GitHub issues for reproducible bugs and focused feature proposals. Include
the PHP and package versions, the selected driver, relevant `image doctor`
output, a minimal example, the expected result, and the actual result.

Use a generated or sanitized image when the source may contain personal data or
private metadata. Usage questions should describe the input format, requested
transform, output format, and storage backend.

Do not post security vulnerabilities in a public issue. Follow the private
reporting process in `SECURITY.md`.
